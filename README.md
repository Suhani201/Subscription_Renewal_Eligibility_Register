# Engine 2 – Logic and Rule Engine

## Project Description
This engine checks subscription details and determines whether a subscriber is eligible for renewal.

## Files
- `eligibilityEngine.js` – Contains the subscription eligibility rules.
- `testEligibility.js` – Contains 12 test cases to validate the eligibility engine.

## Eligibility Results
- **Eligible** – Subscription satisfies all eligibility rules.
- **Not Eligible** – Subscription does not meet an eligibility condition.
- **Needs Correction** – Subscription information is missing or invalid.

## How to Run
1. Install Node.js.
2. Open the project folder in VS Code.
3. Run `npm install` if dependencies are required.
4. Run `npm test`.

## Testing
All 12 test cases passed successfully.
